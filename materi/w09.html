Konsep Kunci

Pola nilai ekstrem (best-so-far) menyimpan nilai terbaik sejauh ini dan menggantinya setiap kali datang nilai yang lebih baik. Nilai awalnya diambil dari data pertama, bukan angka tebakan seperti 0. Pola pencarian memakai return di dalam perulangan: fungsi langsung selesai begitu yang dicari ketemu, dan jawaban tidak ketemu baru dikembalikan setelah perulangan. Pada perulangan bersarang, perulangan dalam berjalan penuh, dari awal, untuk setiap putaran perulangan luar.

def suhu_tertinggi(n):
    tertinggi = int(input())          # ① ambil data pertama
    for hari in range(n - 1):         # ② ulangi sisa data
        x = int(input())
        if x > tertinggi:             # ③ bandingkan dan ganti
            tertinggi = x
    return tertinggi                  # ④ kembalikan setelah loop

def hari_pertama_minus(n):
    for hari in range(1, n + 1):      # ① ulangi setiap data
        x = int(input())
        if x < 0:
            return hari               # ② ketemu? langsung kembalikan
    return -1                         # ③ tidak ketemu: setelah loop

def jumlah_tabel(n):
    total = 0
    for a in range(1, n + 1):         # loop luar: baris
        for b in range(1, n + 1):     # loop dalam: mulai ulang tiap baris
            total = total + a * b
    return total

print(jumlah_tabel(5))                # 225

Lesson A · Nilai Ekstrem dan Pencarian

Masalahnya: suhu yang tidak pernah terjadi

Bulan Juli, suhu subuh di dataran tinggi Dieng bisa turun di bawah 0 °C. Embun di daun kentang membeku, dan petani menyebutnya embun upas. Berikut suhu empat subuh dalam satu minggu:

Subuh 1 2 3 4
Suhu (°C) -3 -1 -4 -2

Subuh mana yang paling hangat? Semua orang langsung menjawab: −1. Sekarang jalankan fungsi ini dengan keempat data tersebut:

def suhu_tertinggi(n):
    tertinggi = 0
    for hari in range(n):
        x = int(input())
        if x > tertinggi:
            tertinggi = x
    return tertinggi

print(suhu_tertinggi(4))
-3
-1
-4
-2
0

Fungsi menjawab 0 °C, suhu yang tidak pernah terjadi di data. Tidak ada pesan galat, loopnya berjalan empat kali, dan > juga sudah benar. Jadi apa yang salah? Simpan dulu tebakanmu; jawabannya ada dua subbab di bawah.

Terbaik sejauh ini

Cara panjang mencari suhu terhangat adalah membandingkan setiap hari dengan semua hari lain. Untuk 30 hari, itu ratusan perbandingan. Lagi pula, input() membaca data satu per satu, dan data yang sudah lewat tidak bisa dilihat lagi.

Cara yang lebih cerdas: ingat satu nilai saja, yaitu yang terbaik sejauh ini. Setiap data baru dibandingkan dengan nilai itu, sekali saja. Jika data baru lebih baik, nilai itu diganti. Penampung ini disebut terbaik sejauh ini (best so far), dan polanya disebut pola nilai ekstrem (extreme value).

Langkah Data baru Lebih hangat? tertinggi
mulai -3 – -3
2 -1 -1 > -3 ya → ganti -1
3 -4 -4 > -1 tidak → tetap -1
4 -2 -2 > -1 tidak → tetap -1

Bayangkan sebuah piala yang dipegang oleh suhu terhangat sejauh ini. Piala hanya berpindah tangan jika muncul penantang yang lebih baik. Di akhir data, siapa pun yang memegang piala adalah jawabannya.

Nilai awal yang aman

Sekarang tebakan Engage bisa dijawab. Pada versi pertama, piala dipegang lebih dulu oleh angka 0, dan nilai awal ikut bertanding. 0 lebih hangat dari semua subuh di data, sehingga tidak ada penantang yang pernah mengalahkannya. Fungsi mengembalikan “pemenang” yang tidak pernah diukur.

Ini berbeda dari akumulator di Minggu 6. total = 0 aman karena menambahkan ke nol tidak mengubah apa pun. Pada pola nilai ekstrem, nilai awal bersaing dengan data, jadi ia harus berupa nilai yang tidak mungkin menang secara curang. Nilai yang selalu aman adalah data pertama itu sendiri: dengan begitu, jawabannya pasti salah satu data yang sungguh ada.

def suhu_tertinggi(n):
    tertinggi = int(input())          # data pertama memegang piala
    for hari in range(n - 1):         # n - 1: satu data sudah dibaca
        x = int(input())
        if x > tertinggi:
            tertinggi = x
    return tertinggi

Dua hal yang perlu diperhatikan:

  • Ini priming read dari Minggu 6. Satu data dibaca sebelum loop, sehingga loop hanya perlu membaca n − 1 data sisanya. Jika ditulis range(n), loop mencoba membaca satu data terlalu banyak, dan Moodle menghentikan program dengan EOFError: EOF when reading a line.
  • Angka “cukup besar” juga jebakan. Untuk suhu terendah, nilai awal 0 gagal jika semua data positif (2 4 6 menghasilkan 0), dan nilai awal 100 gagal jika ada data di atas 100. Data pertama selalu berhasil.

Algoritma dan trace table

Pola nilai ekstrem punya empat langkah. Seperti di Minggu 6, label ini adalah pseudocode kita: tulis dulu sebagai komentar, baru isi kodenya.

① tertinggi ← data pertama
② ulangi untuk n − 1 data sisanya: baca x
③     jika x > tertinggi: tertinggi ← x
④ kembalikan tertinggi (setelah perulangan)
Langkah Python
① Ambil data pertama tertinggi = int(input())
② Ulangi sisa data for hari in range(n - 1): lalu x = int(input())
③ Bandingkan dan ganti if x > tertinggi: lalu tertinggi = x
④ Kembalikan setelah loop return tertinggi, sejajar dengan for

Trace table untuk data -3 -1 -4 -2 (n = 4). Baris (sebelum) mencatat nilai dari langkah ①:

Putaran x x > tertinggi tertinggi
(sebelum) – – -3
1 -1 True -1
2 -4 False -1
3 -2 False -1
return -1

Bandingkan dengan versi Engage: di sana baris (sebelum) berisi 0, dan 0 tidak pernah kalah.

Satu pola, banyak soal

Pola yang sama dipakai untuk setiap pertanyaan “yang paling …”. Yang berubah hanya nama penampung dan arah perbandingannya:

Pertanyaan Penampung Perbandingan
Suhu subuh terhangat tertinggi = int(input()) if x > tertinggi:
Harga termurah murah = int(input()) if x < murah:
Nilai kuis tertinggi top = int(input()) if x > top:
CatatanNilai kembar: > atau >=?

Jika soal menanyakan pada hari ke berapa nilai terbaik terjadi, kamu butuh dua penampung: nilainya dan nomor harinya, dan keduanya diganti bersamaan. Saat ada dua nilai yang sama besar, tanda perbandingan menentukan hari mana yang menang:

def hari_terhangat(n):
    tertinggi = int(input())
    hari_ke = 1
    for hari in range(2, n + 1):      # hari 2 sampai n
        x = int(input())
        if x > tertinggi:             # > : hari pertama yang mencapai nilai itu tetap juara
            tertinggi = x
            hari_ke = hari
    return hari_ke

Dengan data 1 5 3 5, fungsi ini mengembalikan 2. Jika > diganti >=, hari yang terakhir mencapai nilai itu ikut merebut piala, dan hasilnya 4. Baca soalnya: “hari pertama” berarti >, “hari terakhir” berarti >=.

Variasi: penampung sekarang dan penampung terbaik

Kadang yang dicari bukan nilai data, tetapi nilai yang dihitung sambil jalan. Contohnya streak di aplikasi langkah kaki: berapa hari berturut-turut terpanjang target 8000 langkah tercapai?

Hari Sen Sel Rab Kam Jum Sab Min
Langkah 9000 8200 3000 4500 8000 9500 10000
streak 1 2 0 0 1 2 3
terbaik 1 2 2 2 2 2 3

Di sini ada dua penampung. streak adalah keadaan sekarang: bertambah satu saat target tercapai dan kembali ke 0 saat gagal. terbaik adalah terbaik sejauh ini: hanya bisa naik. Nilai awal 0 untuk terbaik aman, karena streak tidak mungkin kurang dari 0.

def streak_terpanjang():
    streak = 0
    terbaik = 0
    for hari in range(7):
        langkah = int(input())
        if langkah >= 8000:               # "minimal 8000": 8000 ikut
            streak = streak + 1
            if streak > terbaik:          # catat rekor saat itu juga
                terbaik = streak
        else:
            streak = 0
    return terbaik

Dengan data di atas, fungsi mengembalikan 3. Jebakan yang sering muncul adalah mencatat rekor hanya saat streak putus, yaitu memindahkan if streak > terbaik: ke dalam else. Hasilnya 2: streak 3 hari di akhir minggu tidak pernah putus, sehingga tidak pernah tercatat. Tanyakan selalu: “bagaimana jika kejadian itu tidak pernah datang?”

TipKata kunci di soal

“Berturut-turut” biasanya berarti butuh penampung yang di-reset. “Terpanjang”, “terbesar”, “termurah” berarti butuh penampung terbaik sejauh ini.

Pencarian: berhenti begitu ketemu

Pertanyaan berikutnya untuk data Dieng: pada hari ke berapa embun beku pertama kali terjadi, yaitu suhu di bawah 0?

Hari 1 2 3 4 5 6 7
Suhu (°C) 4 2 -1 3 -3 0 1

Jawabannya satu nomor hari: 3. Begitu hari 3 ditemukan, hari 4 sampai 7 tidak perlu dilihat lagi, karena jawabannya sudah pasti. Menelusuri data sampai yang dicari ketemu disebut pencarian (search).

def hari_pertama_minus(n):
    for hari in range(1, n + 1):
        x = int(input())
        if x < 0:
            return hari
    return -1

Trace table dengan data 4 2 -1 3 -3 (n = 5):

Putaran x x < 0 Yang terjadi
1 4 False lanjut
2 2 False lanjut
3 -1 True return 3, fungsi selesai
4–5 tidak dijalankan; 3 dan −3 tidak pernah dibaca

Inilah aturan dari Minggu 5 yang kini dipakai dengan sengaja: return mengakhiri fungsi, bukan hanya putarannya (Downey, 2024, Bab 7). Tidak penting bahwa return berada di dalam loop; begitu dijalankan, fungsi selesai saat itu juga, dan putaran sesudahnya tidak pernah ada. Ini berbeda dengan kondisi while di Minggu 6, yang hanya diperiksa di awal putaran: while tidak pernah berhenti di tengah badan loop, sedangkan return berhenti tepat di barisnya.

Bagaimana jika data 4 2 1 3 5, tanpa satu pun suhu di bawah 0? Kelima putaran berjalan, return hari tidak pernah dijalankan, loop selesai, lalu baris terakhir return -1 dijalankan. Hasilnya -1, bukan None: baris return -1 itu benar-benar dicapai.

Pola yang sama berlaku untuk pencarian apa pun, termasuk yang tidak membaca input(). Fungsi pembagi_pertama(n) mencari pembagi pertama n mulai dari 2, atau -1 jika tidak ada (artinya n bilangan prima). Telusuri dua panggilannya dan perhatikan di putaran ke berapa setiap panggilan selesai:

CatatanVersi bendera (flag)

Pencarian juga bisa ditulis dengan satu return di akhir fungsi, memakai variabel penanda (flag):

def hari_pertama_minus(n):
    hasil = -1
    for hari in range(1, n + 1):
        x = int(input())
        if x < 0 and hasil == -1:
            hasil = hari
    return hasil

Jawabannya sama, 3, tetapi kelima hari dibaca (NCCE, t.t.-c). Keduanya benar. Di kuliah ini kita memakai return di dalam perulangan, karena ia menyatakan “ketemu, selesai” dalam satu baris.

Di mana “tidak ketemu” diletakkan?

Prediksi dulu: apa yang dikembalikan fungsi ini untuk data 3 1 -2?

def ada_suhu_minus(n):
    for hari in range(n):
        x = int(input())
        if x < 0:
            return True
        else:
            return False

print(ada_suhu_minus(3))     # False

Jawabannya False, padahal −2 ada di data. Telusuri putaran 1 saja: x = 3, bukan minus, sehingga else dijalankan, return False, dan fungsi selesai. Fungsi memutuskan di hari pertama dan tidak pernah melihat −2.

Kuncinya ada pada perbedaan dua jawaban itu:

  • Ketemu bisa diputuskan dari satu data.
  • Tidak ketemu baru pasti setelah semua data diperiksa.

Karena itu return False diletakkan setelah loop, sejajar dengan for, dan else dihapus:

def ada_suhu_minus(n):
    for hari in range(n):
        x = int(input())
        if x < 0:
            return True
    return False

print(ada_suhu_minus(3))     # data 3 1 -2 → True;  data 3 1 2 → False

Pola pencarian punya tiga langkah:

① ulangi setiap data
②     ketemu? langsung kembalikan (True, atau posisinya)
③ tidak ketemu: kembalikan setelah loop (False, atau -1)
Pertanyaan Saat ketemu Setelah loop
Adakah hari minus? if x < 0: return True return False
Hari minus pertama? if x < 0: return hari return -1
Hari pertama hujan ≥ 50 mm? if x >= 50: return hari return -1

-1 dipilih untuk “tidak ketemu” karena nomor hari selalu dimulai dari 1, jadi -1 tidak mungkin tertukar dengan jawaban yang sah.

Nilai ekstrem atau pencarian?

Dua pola ini sering tertukar. Pertanyaan penentunya: apakah jawabannya bisa dipastikan sebelum semua data dilihat?

Nilai ekstrem Pencarian
Pertanyaan khas “yang paling …”, “berapa …-nya” “adakah …?”, “yang pertama …?”
Data yang dilihat selalu semua sampai ketemu; semua jika tidak ketemu
Letak return satu, setelah loop satu di dalam loop, satu setelah loop
Nilai awal data pertama tidak ada penampung
Contoh suhu terdingin, harga termurah hari pertama minus, adakah nilai di atas 100

“Pada hari ke berapa suhu terdingin?” adalah nilai ekstrem dengan dua penampung (nilai dan harinya), bukan pencarian: hari terdingin baru pasti setelah hari terakhir dilihat.

Contoh terpandu: suhu_terendah

Kita tulis suhu_terendah(n) dengan resep lima langkah dari Minggu 5. Empat label nilai ekstrem adalah isi langkah Rancang.

1 · Pahami. Masukannya n, lalu n suhu yang diketik satu per baris. Keluarannya satu angka, yang terendah; fungsi mengembalikan, tidak mencetak. Hitung dengan tangan untuk 1 -2 0: mulai dari 1, yang terdingin sejauh ini karena satu-satunya. Lalu −2: lebih dingin dari 1? Ya, ganti. Lalu 0: lebih dingin dari −2? Tidak, tetap. Jawabannya −2. Yang dilakukan setiap kali setelah data pertama: bandingkan dengan yang terdingin sejauh ini, ganti jika lebih dingin. Itulah badan loop. Data pertama tidak dibandingkan dengan apa pun; ia langsung diambil.

2–3 · Pecah dan rancang. Satu fungsi cukup. Tulis kerangka, uji dari hitungan tangan, dan empat label sebagai komentar:

def suhu_terendah(n):
    """Kembalikan suhu terendah dari n suhu subuh yang dibaca dari input."""
    # ① AMBIL DATA PERTAMA
    # ② ULANGI SISA DATA
    # ③ BANDINGKAN DAN GANTI
    # ④ KEMBALIKAN SETELAH LOOP
    return 0

Sebelum menulis kode: mengapa tidak mulai dari terendah = 0, seperti total? Karena 0 ikut bertanding. Dengan data 2 4 6, fungsi akan mengembalikan 0, subuh yang tidak pernah ada.

4 · Isi dan uji. Isi satu label setiap kali:

def suhu_terendah(n):
    """Kembalikan suhu terendah dari n suhu subuh yang dibaca dari input."""
    # ① AMBIL DATA PERTAMA
    terendah = int(input())
    # ② ULANGI SISA DATA
    for hari in range(n - 1):
        x = int(input())
        # ③ BANDINGKAN DAN GANTI
        if x < terendah:
            terendah = x
    # ④ KEMBALIKAN SETELAH LOOP
    return terendah
  • ① Subuh pertama adalah yang terdingin sejauh ini.
  • ② Satu data sudah dibaca, jadi tersisa n - 1.
  • ③ Baca subuh berikutnya; jika lebih dingin, ia menjadi yang terdingin sejauh ini.
  • ④ return sejajar dengan for. Jika menjorok di dalam if atau for, fungsi selesai setelah satu perbandingan: data Dieng menghasilkan 2.
n Masukan Harapan Yang diuji
3 1 -2 0 -2 hitungan tangan
7 4 2 -1 3 -3 0 1 -3 data Dieng
3 2 4 -6 -6 yang terendah di akhir
3 2 4 6 2 menangkap nilai awal 0 (jawaban salahnya 0)
1 3 3 kasus tepi: loop berjalan nol kali

Uji keempat penting: dengan data Dieng, versi terendah = 0 kebetulan benar (-3), karena ada data di bawah 0. Satu uji yang lulus belum berarti fungsinya benar.

5 · Rakit.

n = int(input())
print(suhu_terendah(n))

Untuk suhu terhangat, hanya < yang berubah menjadi >.

Lesson B · Perulangan Bersarang dan Konversi while/for

Masalahnya: berapa baris kode untuk tabel perkalian?

Dua baris loop cukup untuk mencetak satu tabel perkalian:

def tabel(t):
    for x in range(1, 11):
        print(f"{x} x {t} = {x * t}")

tabel(5)
1 x 5 = 5
2 x 5 = 10
...
10 x 5 = 50

Sekarang lihat tabel perkalian 1–5 berikut. Berapa baris kode paling sedikit untuk mencetak seluruhnya?

1 2 3 4 5
2 4 6 8 10
3 6 9 12 15
4 8 12 16 20
5 10 15 20 25

Cara salin-tempel memakai lima loop, satu per baris tabel. Untuk tabel 1–20, dua puluh loop. Pasti ada cara yang lebih baik, dan jawabannya ada di akhir subbab berikutnya.

Loop di dalam loop

Perhatikan apa yang berulang pada tabel tadi: untuk setiap baris, untuk setiap kolom, tulis baris × kolom. Yang diulang oleh baris bukan satu perintah, melainkan seluruh perulangan kolom. Perulangan yang berada di dalam badan perulangan lain disebut perulangan bersarang (nested loop), dengan perulangan luar (outer loop) dan perulangan dalam (inner loop).

Mulai dari bentuk yang paling sederhana, persegi bintang 3 × 4:

def persegi():
    for baris in range(3):
        teks = ""
        for kolom in range(4):
            teks = teks + "*"
        print(teks)

persegi()
****
****
****

Setiap baris dibangun sebagai teks baris: mulai dari string kosong, ditambah satu * di setiap putaran dalam dengan + (Minggu 2), lalu dicetak sekali.

Bagian Baris kode Dijalankan
Badan loop luar teks = "", loop dalam, print(teks) 3 kali
Badan loop dalam teks = teks + "*" 4 kali per baris, total 12 kali

Loop dalam mulai lagi dari awal

Berapa kali teks = teks + "*" dijalankan? Banyak yang menjawab 3 + 4 = 7. Trace table menunjukkan sebaliknya:

baris kolom teks Putaran dalam ke-
0 0 1 2 3 * → **** 1–4
1 0 1 2 3 * → **** 5–8
2 0 1 2 3 * → **** 9–12

Loop dalam adalah bagian dari badan loop luar. Setiap kali loop luar menjalankan badannya, loop dalam berjalan dari awal sampai habis: kolom kembali ke 0 di setiap baris, karena loop dalam tidak mengingat di mana ia berhenti. Seperti jam: jarum menit berputar penuh untuk setiap satu jam. Karena itu, jika batas loop dalam tetap:

total putaran dalam = putaran luar × putaran dalam = 3 × 4 = 12

Telusuri versi yang lebih kecil, 2 × 3. Perhatikan nilai kolom saat baris berganti dari 0 ke 1:

Pada perulangan bersarang, setiap baris kode punya tiga kemungkinan tempat, dan setiap tempat berarti frekuensi yang berbeda:

Sebelum loop luar sekali penampung untuk seluruh hasil: total = 0
Di loop luar, di luar loop dalam sekali per baris teks baris: teks = "", print(teks)
Di dalam loop dalam sekali per sel teks = teks + "*", total = total + a * b

Salah satu tingkat saja, hasilnya berubah total:

  • teks = "" sebelum loop luar. Teks tidak pernah dikosongkan, sehingga setiap baris memanjang: untuk 3 baris × 2 bintang tercetak **, ****, ******.
  • print(teks) di dalam loop dalam. Teks dicetak setelah setiap bintang: *, **, ***, ****, diulang tiga kali (12 baris).

CatatanMengapa tidak “” baris saja?

"*" * baris membuat segitiga bintang dengan satu loop (pengulangan string, Minggu 2), dan itu boleh. Namun teks seperti 1234 tidak bisa dibuat dengan pengulangan, karena setiap karakternya berbeda. Untuk teks yang isinya bergantung pada posisi kolom, kita butuh loop dalam.

Contoh terpandu: jumlah_tabel

Tulis fungsi jumlah_tabel(n) yang mengembalikan jumlah semua isi tabel perkalian n × n. Isi baris a, kolom b adalah a * b.

1 · Pahami. Gambar tabel 2 × 2: baris 1 berisi 1 2, baris 2 berisi 2 4. Jumlahnya 1 + 2 + 2 + 4 = 9. Bagaimana mendapatkan setiap angka? Baris × kolom. Apa yang dilakukan setiap kali? Ambil satu isi, tambahkan ke total berjalan: itu akumulator dari Minggu 6. Urutannya: baris 1, setiap kolom; lalu baris 2, setiap kolom. “Untuk setiap baris, untuk setiap kolom” berarti dua loop, satu di dalam yang lain.

2–3 · Pecah dan rancang. Lima label perulangan bersarang:

Label Isinya
① Siapkan penampung sekali, sebelum kedua loop
② Loop luar baris a dari 1 sampai n
③ Loop dalam kolom b dari 1 sampai n, mulai ulang setiap baris
④ Perbarui penampung di dalam loop dalam
⑤ Kembalikan sejajar dengan loop luar

Di mana total = 0: sebelum loop luar, atau di dalam loop luar seperti teks = "" pada persegi? teks adalah milik satu baris, jadi dikosongkan setiap baris. total adalah milik seluruh tabel, jadi dimulai sekali. Jika diletakkan di dalam loop luar, n = 5 menghasilkan 75: hanya jumlah baris terakhir.

4 · Isi dan uji.

def jumlah_tabel(n):
    """Kembalikan jumlah semua isi tabel perkalian n x n."""
    # ① SIAPKAN PENAMPUNG
    total = 0
    # ② LOOP LUAR
    for a in range(1, n + 1):
        # ③ LOOP DALAM (MULAI ULANG TIAP PUTARAN LUAR)
        for b in range(1, n + 1):
            # ④ PERBARUI PENAMPUNG
            total = total + a * b
    # ⑤ KEMBALIKAN
    return total

print(jumlah_tabel(2) == 9)       # True
print(jumlah_tabel(5) == 225)     # True
print(jumlah_tabel(1) == 1)       # True
a b a * b total
(awal) – – 0

1 2 2 3
2 1 2 5
2 2 4 9

return total sejajar dengan for luar. Jika menjorok di dalam loop luar, fungsi selesai setelah baris pertama: n = 3 menghasilkan 6.

PeringatanJangan percaya satu uji

Misalkan kamu salah ketik a + b, bukan a * b. Untuk n = 3, hasilnya 36, sama dengan jawaban yang benar, kebetulan. Untuk n = 5, hasilnya 150, padahal seharusnya 225. Satu uji yang beruntung bisa menyembunyikan bug. Uji lebih dari satu ukuran.

Empat bagian perulangan

Minggu 6 memperkenalkan tiga bagian setiap loop: inisialisasi, kondisi, dan pemutakhiran. Bersama badan loop, keempatnya menjadi alat untuk mengubah satu bentuk loop menjadi bentuk lainnya. for dengan range menyembunyikan tiga di antaranya; while menuliskan semuanya:

Bagian for while
① Inisialisasi range(1, baris + 1) → mulai dari 1 kolom = 1
② Kondisi range(1, baris + 1) → sampai baris while kolom <= baris:
③ Badan teks = teks + str(kolom) teks = teks + str(kolom)
④ Pemutakhiran otomatis oleh for kolom = kolom + 1

Mengubah bentuk perulangan berarti memindahkan keempat bagian ini tanpa mengubah hasilnya.

for → while

Loop dalam segitiga ditulis ulang dengan while:

def segitiga():
    for baris in range(1, 5):
        teks = ""
        kolom = 1                     # ① inisialisasi: DI DALAM loop luar
        while kolom <= baris:         # ② range(1, baris + 1) berhenti sebelum baris + 1
            teks = teks + str(kolom)  # ③ badan
            kolom = kolom + 1         # ④ pemutakhiran, di akhir badan
        print(teks)

Keluarannya sama: 1, 12, 123, 1234. Tiga hal yang dipindahkan:

  • ① kolom = 1 adalah awal range. Letaknya di dalam loop luar, tepat sebelum while, karena loop dalam mulai ulang setiap baris.
  • ② range(1, baris + 1) berhenti sebelum baris + 1, jadi nilai terakhirnya baris, dan kondisinya kolom <= baris.
  • ④ kolom = kolom + 1 ditulis sendiri sebagai baris terakhir badan. Lupa baris ini berarti infinite loop (Minggu 6).

Apa jadinya jika kolom = 1 diletakkan sekali, di atas loop luar?

def segitiga():
    kolom = 1                         # SALAH: hanya sekali
    for baris in range(1, 5):
        teks = ""
        while kolom <= baris:
            teks = teks + str(kolom)
            kolom = kolom + 1
        print(teks)

Setelah baris 1, kolom sudah bernilai 2 dan tidak pernah dikembalikan ke 1. Setiap baris berikutnya hanya mendapat satu angka. Pada for, inisialisasi ini terjadi otomatis setiap kali loop dalam dimulai; pada while, kamu yang harus meletakkannya di tempat yang dijalankan setiap baris.

while → for

Arah sebaliknya: temukan keempat bagian di while, susun menjadi range(awal, batas, langkah), lalu hapus baris pemutakhiran.

# while
def mundur():
    i = 10
    while i >= 1:
        print(i)
        i = i - 3

# for
def mundur():
    for i in range(10, 0, -3):
        print(i)

Keduanya mencetak 10, 7, 4, 1.

Bagian while Menjadi
① i = 10 argumen pertama range: 10
② while i >= 1: batas 0, karena range berhenti sebelum batas
④ i = i - 3 langkah -3, lalu barisnya dihapus

Rumus umumnya: kondisi i <= akhir dengan langkah naik menjadi batas akhir + 1; kondisi i >= akhir dengan langkah turun menjadi batas akhir - 1.

CatatanBaris pemutakhiran yang tertinggal

Jika i = i - 3 lupa dihapus dari badan for, program tidak rusak: for mengisi i lagi dari barisan range di setiap putaran, sehingga perubahan itu hilang. Tetap hapus barisnya, karena ia menyesatkan pembaca: seolah-olah ia yang mengendalikan loop, padahal tidak.

for atau while?

Pertanyaan penentu dari Minggu 6 tetap berlaku: apakah banyak putaran sudah diketahui sebelum loop dimulai?

Situasi Pilihan Alasan
Jumlahkan nilai 4 juri untuk masing-masing 10 peserta lomba for di dalam for 10 dan 4 diketahui sebelum perulangan
Berapa kali n bisa dibagi dua (pembagian bulat) sampai 1 atau kurang? while Banyak putaran bergantung pada nilai n dan tidak bisa ditulis sebagai range
Baca berat barang sampai kasir mengetik 0 while Berhenti pada penanda 0 (sentinel, Minggu 6) 
def dibagi_dua(n):
    kali = 0
    while n > 1:
        n = n // 2
        kali = kali + 1
    return kali

print(dibagi_dua(8), dibagi_dua(100), dibagi_dua(1))    # 3 6 0

Situasi kedua menunjukkan bahwa tidak setiap while bisa menjadi for. Arah sebaliknya selalu bisa: setiap for dengan range dapat ditulis sebagai while dengan memindahkan keempat bagiannya. Jadi pilihannya bukan soal mana yang “lebih kuat”, melainkan mana yang menyatakan maksudnya dengan jelas: for untuk banyak putaran yang diketahui, while untuk berhenti karena sebuah keadaan.

Tebak Dulu

Tanpa menjalankannya, apa keluaran program berikut? Tulis tebakanmu, baru buka jawabannya.

for i in range(3):
    for j in range(2):
        print(i, j)
TipLihat jawaban

Tercetak 6 baris: 0 0, 0 1, 1 0, 1 1, 2 0, 2 1. Perulangan dalam berjalan 2 kali untuk setiap putaran perulangan luar, sehingga totalnya 3 × 2 = 6 iterasi.

Dengan data 4 2 1 3 5 (satu per baris), berapa putaran yang dijalankan, dan apa yang dikembalikan?

def hari_pertama_minus(n):
    for hari in range(1, n + 1):
        x = int(input())
        if x < 0:
            return hari
    return -1

print(hari_pertama_minus(5))
TipLihat jawaban

Kelima putaran berjalan, lalu tercetak -1. Tidak ada suhu di bawah 0, sehingga return hari tidak pernah dijalankan. Setelah loop selesai, baris return -1 dijalankan. Hasilnya bukan None, karena baris terakhir fungsi itu memang dicapai.

Berapa kali teks = teks + "#" dijalankan, dan apa keluarannya?

for baris in range(1, 4):
    teks = ""
    for kolom in range(baris, 4):
        teks = teks + "#"
    print(teks)
TipLihat jawaban

6 kali: 3 + 2 + 1. Keluarannya ###, ##, #. Batas dalam bergantung pada baris, jadi putarannya dihitung per baris lalu dijumlahkan, bukan dikalikan (3 × 3 = 9 salah).

Program berikut seharusnya mencetak persegi 3 × 2. Apa yang sebenarnya tercetak?

teks = ""
for baris in range(3):
    for kolom in range(2):
        teks = teks + "*"
    print(teks)
TipLihat jawaban

**, ****, ******. teks = "" berada sebelum loop luar, sehingga tidak pernah dikosongkan. Setiap baris melanjutkan teks baris sebelumnya. Perbaikannya: pindahkan teks = "" ke dalam loop luar, tepat sebelum loop dalam.
