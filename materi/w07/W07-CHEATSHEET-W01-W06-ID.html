W03

Kondisional & guard

U3.1–U3.5

Ekspresi Boolean → True / False

== sama · != tidak sama · < <= > >=. Dengan nilai = 75: nilai >= 70 → True, nilai != 75 → False.

and True jika kedua sisi True · or True jika minimal satu sisi True · not membalik. Urutan: perbandingan → not → and → or. = menempelkan nama; == bertanya.

if hari == "Sabtu" or "Minggu": selalu True (teks dianggap True). Tulis kondisi lengkap di tiap sisi: hari == "Sabtu" or hari == "Minggu". Begitu juga x > 0 and x < 10, bukan x > 0 and < 10.

if · if-else · if-elif-else

if nilai >= 80:
    huruf = "A"
elif nilai >= 70:
    huruf = "B"
else:
    huruf = "C"
print(huruf)   # di luar blok

Diperiksa dari atas; berhenti di kondisi True pertama; tepat satu cabang dijalankan.

Indentasi menentukan baris mana yang ikut sebuah cabang.

Dua if terpisah = dua keputusan; elif = bagian keputusan yang sama.

Urutkan rentang dari yang paling ketat: >= 60 di atas membuat 95 dapat C.

Bersarang: keputusan di dalam keputusan

if dalam if hanya diperiksa bila kondisi luarnya True. Setiap else berpasangan dengan if pada indentasi yang sama. Tanpa else, bisa diratakan:

if punya_tiket:
    if umur >= 13:
        print("Masuk")
if punya_tiket and umur >= 13:
    print("Masuk")

elif berantai: satu variabel, rentang tak tumpang tindih · bersarang: pertanyaan kedua bergantung pada yang pertama.

Guard: periksa masukan sebelum diproses

umur_teks = input()               # BACA
if not umur_teks.isdigit():       # GUARD
    print("Harus angka bulat")
else:
    umur = int(umur_teks)         # UBAH
    if umur > 120:                # TOLAK
        print("Tidak masuk akal")
    elif umur >= 17:              # CEK SYARAT
        print("Boleh membuat KTP")
    else:
        print("Belum cukup umur")

Pola: BACA → GUARD → UBAH → TOLAK → PILIH KATEGORI → CEK SYARAT, tiap langkah di dalam else langkah sebelumnya. "20".isdigit() True · "-3".isdigit() False.

W04

Fungsi, parameter, lingkup

U4.1–U4.5

Anatomi fungsi

def cetak_tagihan(nama, total):        # header
    """Mencetak tagihan satu pelanggan."""  # docstring
    print(f"{nama}: Rp{total}")         # badan

cetak_tagihan("Ani", 45000)            # posisi
cetak_tagihan(total=45000, nama="Ani") # kata kunci

def hanya mencatat fungsi; badannya jalan saat dipanggil (tanpa pemanggilan, tidak ada keluaran). Parameter = nama di kurung header; argumen = nilai yang dikirim, dipasangkan menurut urutan (atau menurut nama, untuk argumen kata kunci). help(cetak_tagihan) menampilkan docstring.

Stack diagram

Setiap pemanggilan mendapat frame sendiri berisi parameter dan variabel lokalnya. Frame hilang saat fungsi selesai.

__main__

Traceback dibaca dari baris terakhir (jenis galat) ke atas (baris pemicunya).

Fungsi void dan None

Fungsi tanpa return melakukan aksi, tetapi hasilnya None.

hasil = cetak_tagihan("Ani", 0)   # mencetak Ani: Rp0
print(hasil)                       # None

Lingkup (scope)

Variabel di dalam fungsi bersifat lokal: tidak terlihat di luar (→ NameError).

skor = 0
def tambah_skor():
    skor = skor + 1   # UnboundLocalError

Nilai masuk lewat parameter, keluar lewat return (W05), bukan lewat variabel global.

Enkapsulasi → generalisasi

Enkapsulasi: kode berulang → satu fungsi. Generalisasi: nilai tertanam → parameter: cetak_garis() → cetak_garis(panjang). Dekomposisi: satu fungsi, satu tugas.

Beberapa jalur return

def tarif_layanan(layanan):
    if layanan == "kilat":
        return 9000
    elif layanan == "reguler":
        return 6000
    return 0          # tanpa ini → None
    print("selesai")  # kode mati

Setiap jalur harus bertemu return; jalur tanpa return menghasilkan None. Baris sesudah return tidak pernah dijalankan.

Fungsi boolean

def dapat_diskon(belanja):
    return belanja >= 100000
if dapat_diskon(150000):
    print("Diskon!")

Kembalikan ekspresinya langsung; tidak perlu if … return True else return False atau == True.

Komposisi fungsi

Hasil satu fungsi dipakai di fungsi lain:

biaya = tarif_layanan(layanan) * berat - potongan(berat, layanan)

Resep 5 langkah

  1. Pahami: tulis ulang soal; tentukan input, output, dan satu contoh hitungan tangan.
  2. Pecah: satu sub-tugas = satu fungsi.
  3. Rancang: header + docstring + return 0 + satu baris uji.
  4. Isi & uji: satu fungsi sampai ujinya True, baru lanjut. Uji juga nilai batas (tepat 4 kg pada aturan "lebih dari 4 kg").
  5. Rakit bagian utama: input() → panggil fungsi → print().
Mencetak ≠ mengembalikan. Jika ongkir hanya print(berat * 10000) tanpa return, maka ongkir(2) + 5000 → TypeError (None + int).

Perulangan for & while

U6.1–U6.5

for dengan range: batas tidak ikut

range(…)nilai variabel looprange(…)nilai
range(4)0 1 2 3range(2, 11, 3)2 5 8
range(1, 4)1 2 3range(5, 0, -2)5 3 1
range(1, n + 1)1 … nrange(5, 0)0 putaran

Sesudah loop, variabel loop menyimpan nilai terakhir: setelah for k in range(2, 11, 3), k = 8.

Akumulator & pencacah di dalam fungsi

def total_tabungan(minggu):
    """Setoran minggu ke-k = k × 10000."""
    total = 0              # sebelum loop
    for k in range(1, minggu + 1):
        total = total + k * 10000
    return total           # sejajar for

print(total_tabungan(3))   # 60000

Akumulator: total = total + x · Pencacah: banyak = banyak + 1 (biasanya di dalam if). Penampung diberi nilai awal sebelum loop; return sesudah loop.

while: kondisi diperiksa sebelum tiap putaran

① inisialisasi sebelum loop · ② kondisi · ③ proses · ④ pemutakhiran di akhir badan. Bisa berjalan 0 kali. Tentukan kapan berhenti, lalu balik: "berhenti saat -1" → while hujan != -1:

def total_hujan():
    """Total hujan sah; -1 selesai, -9 rusak."""
    total = 0
    hujan = int(input())       # ① baca nilai pertama
    while hujan != -1:         # ② sentinel tidak diproses
        if hujan != -9:        # ③ guard + akumulasi
            total = total + hujan
        hujan = int(input())   # ④ baca berikutnya, sejajar if
    return total               # ⑤

print(total_hujan())  # 12 -9 30 0 -1 → 42

Rata-rata: dua penampung, lalu jaga pembagian: if banyak > 0: return total / banyak, lainnya return 0.

for: banyak putaran diketahui sebelum loop · while: berhenti karena nilai yang datang (data diakhiri -1).

Infinite loop: pemutakhiran lupa, atau input() berikutnya masuk ke dalam if. Off-by-one: hari = 0 lalu while hari <= 7 → 8 putaran. Tanpa baca nilai pertama, -1 ikut dijumlah.
